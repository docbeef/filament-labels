# Filament Labels

Search a 3D-printer filament, check or edit its settings, and save a sticker image for a
**Phomemo M02** (384 px, 1-bit, 48 mm printed width). Print it from the Phomemo app. Works offline
once added to the home screen.

**Open it:** https://docbeef.github.io/filament-labels/

Values come from community databases and can be wrong or out of date. Check them against the
box. Orange / "typ" values are typical for the material, not that filament's own numbers.
